# Test: Windows Skills, Star Web, Forge, Atlas

Open via the menu on the left (visible when idle) or by key. Only one window at a time; × or the same key closes it.
As long as the scene images and nodes from ChatGPT are missing (`Assets.Art` empty), you see a darkened background and slots as nodes.

## Skills (key K)
- [ ] Q/E/R/F at the top and the list on the left show the 4 skills; tapping selects a skill (gold frame)
- [ ] Center: skill bloom with trunk + 2 branches, nodes 0/5; tapping a node shows text at the bottom
- [ ] Right: name, description, damage / cooldown / range match the game
- [ ] "Equipped" is greyed out (swapping comes later)

## Star Web (key N)
- [ ] Heart in the center, branches Strength (orange), Dexterity (blue), Wisdom (purple) with lines
- [ ] Points top right = player level minus assigned points
- [ ] "Assign" only next to already assigned stars; big star costs 2
- [ ] "Remove" only at the end of a branch; "Reset" clears everything
- [ ] Hint "Preview" visible (has no effect yet, isn't saved)

## Forge (key B)
- [ ] Top left all items (equipped first); tapping switches
- [ ] Affixes as rows, free slot with plus; tapping an affix → status "Ready"
- [ ] Right 4 actions with costs, hammer buttons greyed out
- [ ] Without items: hint text instead of a crash

## Atlas (key M)
- [ ] 6 regions with signs and dotted paths; only Green Plains without a lock
- [ ] Profile on the right changes on tap
- [ ] "Travel" at Green Plains starts the rift and closes the Atlas; in the rift it says "Already in a rift"
- [ ] Locked regions: button "Locked"

## Settings (gear on the HUD, at rest)
- [ ] Gear opens the Settings window (no menu dock over it); X closes it back to the game
- [ ] Sound: "Mute all" silences everything; each slider changes its channel while dragging
      (music, combat sounds, ambience, interface) and keeps the value after release
- [ ] Camera shake Off / Low / Full: hits and kills shake less or not at all
- [ ] Damage numbers off: no numbers over hit enemies; "Dodged!", own hurt numbers and texts still show
- [ ] Effects quality Low: fewer flying bricks on kills, minimap shows fewer parts; Auto on a phone = Med
- [ ] Minimap off hides the compass map; on brings it back
- [ ] HUD size XS..XL rescales the HUD at once (phone, tablet, PC); nothing leaves the screen at XL on a phone
- [ ] Camera speed changes how fast mouse drag / finger swipe turns the camera
- [ ] "Defaults" resets everything; "Roblox Menu" closes the window and opens the Roblox menu
- [ ] Rejoin (or switch hero): every setting is still the same (saved per account)
- [ ] Phone: sliders drag with a finger, every switch and option is easy to hit

## Journey (Journey button left of the daily chest, at rest)
- [ ] Opens with the next goal on the left (progress bar, reward), hero facts, "x / 20 milestones claimed"
- [ ] Finished milestones sit at the top with a gold Claim button; claiming toasts and pays (gold, materials, stones, Soulstars)
- [ ] Gold dot on the button while a milestone waits; gone after claiming the last one
- [ ] Switch hero: the list shows the other hero's milestones

## Beta Season (Season button left of the daily chest, at rest)
- [ ] Badge, "Open season · runs until Season 1 arrives" (no countdown), points bar with 5 ticks and 5 reward cards
- [ ] Challenges count while playing (kills, cleared depths, salvage, forge, stars …); a toast on each finished one
- [ ] Dbg "Season: Next Challenge" finishes one; at 20 / 50 points the step's Claim button appears
- [ ] Claiming "Beta Trail" / "Beta Aura" puts it on the hero (wardrobe in the Shop's Cosmetics tab)
- [ ] Gold dot on the button while a step waits

## General
- [ ] No error in the output at startup and when opening each window
- [ ] Windows fit with a small and a large Studio window (scaling like the inventory)
