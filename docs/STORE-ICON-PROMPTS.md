# Store Icon Prompts

Ready-to-paste image prompts (ChatGPT image generator) for every Roblox badge, game pass and developer product.
All icons are 512x512 PNG. Roblox crops badge icons to a circle: keep the subject inside the middle ~80%.
Lists: badges in `docs/BADGES.md` (`src/shared/Badges.luau`), passes and products in `docs/MONETIZATION.md` (`src/shared/Monetization.luau`).

## Shared style

Every prompt below already contains this block, so each one can be pasted alone:

```
Style: glossy toy-brick game world made of plastic bricks with round studs on top, bold chunky shapes, saturated colors, soft studio lighting with a strong highlight from the top-left, subtle rim light. Framed by a polished dark graphite ring with a thin gold inner bevel and small gold corner accents. Background: deep graphite radial gradient with a soft colored glow behind the subject. Centered, one clear subject filling about 70% of the frame, thick clean silhouette that stays readable at 64x64 pixels. No text, no letters, no numbers, no logos, no watermark, no realistic humans. Square 512x512, PNG.
```

Tips: generate all icons of one group in the same chat so the style stays consistent; if the model adds text, reply "same image, remove all text". Upload: Creator Hub, experience → Associated Items (badges) / Monetization (passes, products) → the item → icon.
