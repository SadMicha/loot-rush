## Caveats
- The Studio MCP sends synthetic mouse moves with `Delta = 0`; drag tests need many small `moveTo` steps and cursor-based panning.
- `screen_capture` shows GUI reliably, 3D is often dark.
- Rojo only syncs scripts in Edit mode; editing a script in Studio can stop it applying disk changes.
- The test place equals the published main build unless Rojo is connected.
